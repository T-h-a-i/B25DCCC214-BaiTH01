Giới thiệu bản thân

Xin chào! Tôi là một nhà phát triển Web đam mê với việc tạo ra các sản phẩm công nghệ đẹp mắt và hữu ích. Tôi luôn nỗ lực học hỏi để hoàn thiện bản thân mỗi ngày.

Kỹ năng của tôi

HTML5 CSS3 (Flexbox/Grid) JavaScript Responsive Design

Dự án tiêu biểu

Dự án 1: To-Do App

Ứng dụng quản lý công việc hàng ngày sử dụng HTML, CSS và JavaScript thuần.

Dự án 2: Thời Tiết

Website hiển thị thời tiết theo thời gian thực sử dụng API thời tiết.

Dự án 3: Web Bán Hàng

Giao diện trang web thương mại điện tử với tính năng giỏ hàng.
